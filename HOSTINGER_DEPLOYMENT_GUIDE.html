5. 24/7 Background Systemd Services

Create two dedicated systemd services so the dashboard and AI heartbeat runner start automatically on boot and restart if any failure occurs.

Service 1: Harvey Dashboard (/etc/systemd/system/harvey-dashboard.service)

[Unit]
Description=Obrive Leads Web Dashboard & Outbox API
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/var/www/leads
EnvironmentFile=/var/www/leads/.env
ExecStart=/var/www/leads/.venv/bin/python3 -m harvey dashboard
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Service 2: Harvey Heartbeat Runner (/etc/systemd/system/harvey-runner.service)

[Unit]
Description=Obrive Leads Autonomous Heartbeat Runner
After=network.target harvey-dashboard.service

[Service]
Type=simple
User=root
WorkingDirectory=/var/www/leads
EnvironmentFile=/var/www/leads/.env
ExecStart=/var/www/leads/.venv/bin/python3 -m harvey run
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

Enable and Launch Both Services:

sudo systemctl daemon-reload
sudo systemctl enable --now harvey-dashboard
sudo systemctl enable --now harvey-runner

6. Nginx Reverse Proxy, Basic Auth & SSL

Step 6.1: Create Password Protection for Dashboard

Create credentials for accessing https://obleads.obrive.com:

sudo htpasswd -c /etc/nginx/.ob_leads_passwd admin
# Enter your desired secure password when prompted

Step 6.2: Configure Nginx Site

Create /etc/nginx/sites-available/obleads.conf:

sudo nano /etc/nginx/sites-available/obleads.conf

Add the following configuration:

server {
    listen 80;
    server_name obleads.obrive.com;

    # Protect the entire dashboard with HTTP Basic Auth
    auth_basic "Obrive Leads Executive Portal";
    auth_basic_user_file /etc/nginx/.ob_leads_passwd;

    # Reverse proxy to local Harvey Dashboard port 5555
    location / {
        proxy_pass http://127.0.0.1:5555;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120;
    }

    access_log /var/log/nginx/obleads_access.log;
    error_log /var/log/nginx/obleads_error.log;
}

Step 6.3: Activate Site & Verify Nginx

sudo ln -s /etc/nginx/sites-available/obleads.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

Step 6.4: Install Free Let's Encrypt SSL Certificate

Run Certbot to automatically configure HTTPS and auto-redirect HTTP:

sudo certbot --nginx -d obleads.obrive.com --non-interactive --agree-tos -m info@obrive.com
